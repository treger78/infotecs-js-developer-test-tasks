# infotecs-js-developer-test-tasks

# TECTOBOE ЗАДАНИЕ

## Задание №1
Необходимо отобразить коллаж с фотографиями животных:

1. Получить изображения с помощью стороннего API [https://dog.ceo/dog-api/](https://dog.ceo/dog-api).

2. Добавлять в коллаж новые изображения каждые 3 секунды.

3. Заменять старые изображения, если они не помещаются в контейнер или достигнут лимит изображений.

4. Открывать изображения в режиме просмотра. Обновление коллажа приостанавливается, если изображение открыто в режиме просмотра.

5. Добавить возможность скачивать изображения в режиме просмотра.

## Задание №2
Нужно отобразить таблицу с пользователями:

1. Получить данные о пользователях с помощью стороннего API [https://dummyjson.com/docs/users](https://dummyjson.com/docs/users).

2. Вывести полученные данные в таблицу.

3. Реализовать постраничное отображение данных.

4. Реализовать сортировку записей для каждой колонки.

5. Реализовать отображение боковой панели с постами выбранного пользователя.
